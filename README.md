# RAISE by AGRIVA

Flutter-based mobile app for AI-assisted rice crop health, disease and stress screening.

## Planned modules
- Home dashboard
- Rice plant scan
- My Fields
- Scan reports and history
- Rice disease/stress knowledge library
- Farmer profile
- Crop growth timeline
- Crop health dashboard
- Authentication

## Android
Package ID: `bd.com.agriva.raise`

## Note
AI results are assistive screening only and are not a definitive agricultural diagnosis.
